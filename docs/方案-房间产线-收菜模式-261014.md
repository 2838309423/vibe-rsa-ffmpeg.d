## 2. 产线设计：五段自动 + 两处人工

```
你给主题一句话（睡前 1 分钟）
   │
   ▼
① doc.txt 口播稿 + storyboard.json 镜头表     ← LLM 生成（"脚本驱动生成脚本"就在这一步）
   │     每镜头：房间状态(乱/整)·机位·时长·字幕行·旁白文本
   ▼
② TTS 逐段合成（cosyvoice-v2）→ 每段时长自动反推镜头帧数（音画自动对齐，零人工）
   ▼
③ build_scene.py：blueprint.json → 房间壳(程序化墙地窗光) + 素材按坐标落位
   │     两态同源：乱序态 A / 整洁态 B（同一蓝图两个摆放参数组）
   ▼
③½ 【门 B · 关键帧图包评审】每镜头 1 帧低采样快渲（640×360 ≈ 2s/帧，全套 <2 分钟）
   │     图包 = 编号帧 + 摆放说明 + 旁白行；你逐帧批注（过/改/换机位/挪道具）
   │     ⚠ 渲染前唯一硬闸：**批不过，整片渲染不启动**
   ▼
④ render_shots.py：逐镜头渲染 PNG 序列（断点续渲：已有帧跳过，中断重跑即续）
   ▼
⑤ assemble（ffmpeg 拼接+转场+字幕烧录+loudnorm）→ qc_check.py 自动质检
   ▼
你收菜：projects/<片>/out/ 下看 QC报告.md + 成片.mp4 + 预览.gif，回「过 / 改」
```

**人工介入点全表（每片固定 2 处 = 门 B + 门 C，另有门 A 一次性）**：

| # | 时机 | 动作 | 耗时 |
|---|---|---|---|
| H1 | 一次性 | 门 A：首个房间 blueprint 审美拍板（4 张预览图） | 5 分钟 |
| H2 | **每片·渲染前** | **门 B：分镜清单 + 关键帧图包评审**（逐帧批注） | 5~10 分钟 |
| H3 | 每片可选 | 旁白想要你本人的声音：照 doc.txt 录一条发我（否则默认 TTS） | 0 或 5 分钟 |
| H4 | 每片 | 门 C：终审成片（预览.gif + QC 报告），回"过/改" | 3 分钟 |

> 门 B 的道理（甲方 2026-10-14 口径）：AI 对物理世界与受众心理的理解现阶段弱于人类——
> 悬浮穿模、朝向反常、光影不对这类"物理失真"，以及"这画面到底传达没传达出乱/整洁的情绪"、
> 机位怪不怪、节奏顺不顺这类"受众感受"，必须由人眼在**最贵一步（整片渲染）之前**把关。
> 关键帧快渲成本可忽略（~2s/帧），拦下的返工成本是 3 小时渲染。

**门 B 评审视表**（每帧随图给四行标注：镜头号 / 状态·机位说明 / 摆放了什么 / 该帧旁白行 + 时长），
你按四个维度批注即可，格式 `#3 改：衣柜换个朝向`、`#7 过`（机器可解析，批完直接回炉）：

| 维度 | 看什么（AI 弱项所在） |
|---|---|
| 物理合理 | 悬浮、穿模、朝向反常、比例失真、光影方向不对 |
| 情绪传达 | 这帧一眼看去是不是"乱"（前段）/"整洁"（后段）——受众第一眼感知 |
| 机位构图 | 主体清不清楚、视角怪不怪、要不要换机位 |
| 声画节奏 | 这句旁白配这幅画面对不对、镜头时长够不够读完字幕 |

## 3. 及格线（qc_check.py 自动判定，不达标不出片）

- 画幅 886×1920（竖屏，与既有线一致）或 1280×720（横屏，蓝图里二选一）；帧率恒定 30
- 时长 30–90s；H.264 + AAC；视频码率 ≥ 1.2 Mbps；音频 loudnorm `I=-16`
- 全程烧录字幕（中文，思源黑体）；首尾无黑场（`blackdetect` 零异常）、无冻结帧（`freezedetect` 零异常）
- 断言风格沿用 `bin/verify_video.py`，QC 报告落 `out/QC报告.md`（绿/红逐项）
